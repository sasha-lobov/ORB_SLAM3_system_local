# ORB_SLAM3_system_local
Pet-проект по исследованию и реализации системы локальной навигации БПЛА в условиях отсутствия GNSS.

Система использует монокулярную камеру, алгоритм ORB-SLAM3 для визуальной одометрии, ПИД-регулятор для трекинга траектории и динамическую коррекцию масштаба на основе инерциальных данных.

## Архитектура системы
Система построена по распределённому принципу «симулятор → бортовой компьютер → контур управления»:

<img width="974" height="405" alt="image" src="https://github.com/user-attachments/assets/3b7c8917-f5b4-44ce-b9fd-b24dc17fc304" />

Ключевые блоки:
- sender.py — трансляция видеопотока из AirSim в SLAM через ZeroMQ
- ORB-SLAM3 — визуальная одометрия (монокулярный режим)
- ROS-нода — преобразование систем координат (NED ↔ ENU/Camera) и публикация позы
- Smoothing Filter — скользящее среднее для сглаживания шумов одометрии.
- Dynamic Scaler — онлайн-калибровка масштаба по данным IMU/акселерометра
- PID Controller + Lookahead — трекинг траектории с компенсацией задержки SLAM

## Как работает система

### 1) Проблема масштаба в монокулярном SLAM
ORB-SLAM3 возвращает траекторию в условных единицах (unit). При каждой повторной инициализации (потере трекинга) масштаб сбрасывается случайным образом, что приводит к дрейфу позиции (ATE 2.0–2.3 м):

<img width="654" height="532" alt="image" src="https://github.com/user-attachments/assets/dd0cce63-6ab1-49b8-9d8d-b80f0eed498e" />

### 2) Динамическая коррекция масштаба
Система сравнивает скорость/перемещение, оценённую по SLAM, с реальной скоростью дрона из AirSim IMU:
```
instant_scale = gt_speed / orb_speed
new_scale = (1 - α) * current_scale + α * instant_scale  # EMA-фильтр
```
Это позволяет удерживать метрический масштаб даже после сбоя визуального трекинга.

### 3) Фильтрация и компенсация задержки
- Скользящее среднее (FILTER_WINDOW=5) убирает высокочастотный шум карты
- Lookahead-экстраполяция (LOOKAHEAD_TIME=0.15s) компенсирует задержку между получением кадра и выдачей позы SLAM

### 4) ПИД-регулятор
Управление только по горизонтали (XY), высота фиксируется (Z-LOCK). Используется P+D схема с ограничением скорости и гистерезисом переключения вейпоинтов. При потере данных SLAM (>300 мс) дрон автоматически переходит в режим зависания (hover).


## Установка и запуск

### 1) Требования
- Python 3.10
- AirSim (с Unreal Engine или из бинарных файлов)
- Скомпилированный ORB-SLAM3
- ROS (для моста данных)
- Пакеты: airsim, pyzmq, numpy, opencv-python, matplotlib

### 2) Настройка AirSim
- в папке симулятора создайте/отредактируйте settings.json
- убедитесь, что камера включена, разрешение 640x480, FOV=90°, автоэкспозиция выключена
- добавьте текстурированные объекты в сцену для стабильной работы ORB-фич

### 3) Запуск
- запустите AirSim
- запустите транслятор видео
- python sender.py
- запустите ORB-SLAM3 (в отдельном терминале)
  (укажите путь к вашей сборке)
  ./Examples/Monocular/mono_euroc path_to_vocabulary path_to_config
- запустите контроллер (выберите траекторию)
  python flight_slam.py      # Квадрат
  python flight_circle.py    # Окружность
  python flight_imu.py       # Хаотичная траектория
